# Journey With Love ✦

Sebuah website dokumentasi dan catatan perjalanan — kisah-kisah yang kita tulis bersama.

## Struktur File

```
Journey With Love/
├── index.html          # Halaman utama
├── css/
│   └── style.css       # Styling (dark theme, glassmorphism)
├── js/
│   └── script.js       # Interaktivitas (scroll, nav, loader)
├── images/             # Folder untuk foto-foto kita
└── README.md           # File ini
```

## Fitur

- 🎨 **Dark theme** dengan aksen emas/temanggung
- 🌀 **Glassmorphism** cards & effects
- ✨ **Scroll animations** (AOS-style)
- 📱 **Fully responsive** — mobile-friendly
- ⏳ **Loader** animasi saat halaman dibuka
- 🧭 **Navigation** fixed dengan scroll effect
- 📸 **Gallery grid** dengan hover overlay
- 📅 **Timeline** dua sisi
- 🗺️ **Peta / rute** destinasi

## Customisasi

1. **Ganti foto placeholder** di gallery section → ganti emoji dengan `<img>` tag ke file di `/images/`
2. **Tambah timeline item** baru di bagian `#timeline`
3. **Edit konten** langsung di `index.html`
4. **Ubah warna** di `css/style.css` → section `:root`

## Development

Buka `index.html` langsung di browser. Atau pakai local server:

```bash
cd "Journey With Love"
python3 -m http.server 8000
# Buka http://localhost:8000
```
